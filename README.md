# Large Text File Search — Work in Progress

**University Programming Project | Universidad de La Sabana**

## Overview

This is a collaborative university project developed in Python.

Our goal is to build an efficient text-processing application capable of searching and analyzing words in large text files.

The project explores different searching strategies, data structures, and their impact on execution time and memory usage.

## Project Status

🚧 **Work in Progress**

The project is currently under development. Some modules have been completed, while others are being integrated by team members.

## Implemented Features

- Text file loading and indexing.
- Exact word search.
- Word frequency and position tracking.
- Performance comparison between linear search and dictionary-based lookup.

## Features in Development

- Simple word search.
- Prefix-based search.
- Text statistics.
- Word lookup by position.

## Technologies

- Python 3.10+
- Dictionaries and arrays
- Algorithms and data structures
- Execution time measurement

## Project Structure

- `main.py` — Main menu and program control.
- `librerias.py` — Data processing and search functions.
- `Archivos/` — Directory for text files.

## How to Run

1. Download or clone the repository.
2. Open the project directory.
3. Run `python3 main.py`.
4. Follow the menu instructions.

**Note:** Not all menu options are functional yet.
